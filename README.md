# 🩺 DermaCare – Дерматологиялық медициналық мобильді қосымша

## Жоба туралы

**DermaCare** – адамдарға тері денсаулығын бақылауға, дерматолог дәрігерлерді табуға және медициналық кеңес алуға көмектесетін мобильді қосымша.

Бұл жоба Appstorm пәні бойынша оқу жобасы ретінде әзірленді.

**Жоба авторы:** Лесбек Диас  
**Пәні:** Appstorm  
**Жоба атауы:** Medical Health – Dermatology Doctor Mobile App  
**Платформа:** Android және iOS  
**Технология:** React Native  
**Қосымша ортасы:** Expo

---

## 🎯 Жобаның мақсаты

Жобаның негізгі мақсаты – пайдаланушыларға дерматологиялық қызметтерді қолжетімді ету, дәрігерге жазылуды жеңілдету және тері күтімі туралы пайдалы ақпарат ұсыну.

## ⚙️ Қосымшаның негізгі мүмкіндіктері

### 1. Басты бет (Home)
- Қосымшаның негізгі мәзірі.
- Тері күтімі туралы кеңестер.
- Негізгі медициналық қызметтер.
- Танымал дәрігерлер тізімі.

### 2. Дәрігерлер (Doctors)
- Дерматолог дәрігерлер тізімі.
- Дәрігерлерді аты бойынша іздеу.
- Мамандығы мен тәжірибесі туралы ақпарат.
- Дәрігер рейтингін көру.

### 3. Дәрігер профилі (Doctor Profile)
- Дәрігердің аты-жөні.
- Мамандығы.
- Жұмыс тәжірибесі.
- Қызмет түрлері.
- Қабылдау бағасы.

### 4. Қабылдауға жазылу (Appointments)
- Дәрігерді таңдау.
- Қабылдау күнін белгілеу.
- Уақытты таңдау.
- Жазылуды растау.
- Алдағы қабылдауларды көру.

### 5. Хабарламалар (Chat)
- Дәрігермен хабарласу интерфейсі.
- Хабарлама жіберу.
- Жауаптарды көрсету.

### 6. Тері жағдайын тексеру (Skin Health Check)
- Безеу мәселелері.
- Терінің құрғауы.
- Қызару және тітіркену.
- Тері дақтары мен меңдер туралы ақпарат.

### 7. Пайдаланушы профилі (Profile)
- Жеке мәліметтер.
- Аты-жөнін өзгерту.
- Электрондық пошта мекенжайын өзгерту.
- Жеке баптаулар.

## 🚀 Қосымшаны іске қосу

Алдымен компьютерге Node.js және Expo орнатылуы қажет.

**1-қадам.** Жоба орналасқан папканы ашу.

**2-қадам.** Терминалға келесі команданы енгізу:

```bash
npm install
```

**3-қадам.** Қосымшаны іске қосу:

```bash
npx expo start
```

**4-қадам.** Expo Go арқылы QR-кодты сканерлеп, мобильді құрылғыда ашу.

Android эмуляторында іске қосу үшін:

```bash
npm run android
```

## 🎨 Дизайн ерекшеліктері

Қосымшаның интерфейсі заманауи медициналық стильде жасалған.

Негізгі түстер:
- Ақ – тазалық пен қарапайымдылық.
- Көгілдір – медицина және сенімділік.
- Ашық көк – жайлылық пен заманауилық.

Интерфейс пайдаланушыға түсінікті және қолдануға ыңғайлы етіп жасалған.
