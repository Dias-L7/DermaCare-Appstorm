# DermaCare — мобильное приложение дерматологии

**Автор:** Лесбек Диас  
**Дисциплина:** Appstorm  
**Платформа:** Android / iOS  
**Технология:** React Native + Expo + TypeScript

## 1. Описание проекта

DermaCare — учебное мобильное приложение для взаимодействия пациентов с дерматологами. Приложение помогает находить специалистов, просматривать их профили, записываться на консультации, вести переписку и получать общую информацию о здоровье кожи.

Интерфейс выполнен в современном медицинском стиле: светлый фон, бирюзовые акценты, карточки с закруглёнными углами и нижняя панель навигации.

## 2. Основные возможности

- Главная страница с приветствием, сервисами и рекомендацией дня.
- Каталог дерматологов с поиском по имени и специализации.
- Карточка специалиста с опытом, рейтингом, услугами и стоимостью консультации.
- Запись на приём: выбор даты и времени, подтверждение записи.
- Раздел предстоящих приёмов с локальным списком записей.
- Демонстрационный чат с врачом: отправка сообщений и ответы-заглушки.
- Профиль пациента с редактированием имени и электронной почты.
- Информационный раздел Skin Health Check с типичными проблемами кожи.
- Переключение вкладок без перезагрузки приложения.

## 4. Требования

Перед запуском установите:

- Node.js (рекомендуется LTS);
- npm;
- Expo Go на Android/iOS или Android Studio для эмулятора;
- Git (необязательно).

## 5. Установка и запуск

1. Распакуйте архив проекта.
2. Откройте терминал в папке `dermacare_mobile`.
3. Установите зависимости:

```bash
npm install
```

4. Запустите Expo:

```bash
npx expo start
```

5. Для запуска на Android нажмите `a` в терминале либо отсканируйте QR-код приложением Expo Go.
6. Для запуска в браузере выполните:

```bash
npm run web
```

## 7. Демонстрационные данные

В приложении используются демонстрационные профили врачей и пациента. Записи и сообщения хранятся в состоянии приложения и предназначены для демонстрации пользовательских сценариев. После полного перезапуска приложения эти данные могут сбрасываться.

## 8. Ограничения и дальнейшее развитие

Текущая версия является функциональным учебным прототипом. Для промышленного использования необходимо добавить:

- серверную часть и базу данных;
- безопасную авторизацию и восстановление пароля;
- защищённое хранение медицинских данных;
- реальный чат и видеоконсультации;
- интеграцию с календарём и push-уведомлениями;
- загрузку фотографий через системную галерею;
- проверенную медицинскую модель анализа изображений;
- журнал согласий и политику конфиденциальности.

**Важно:** раздел Skin Health Check носит информационный характер. Приложение не ставит диагноз и не заменяет консультацию квалифицированного врача. Демонстрационный интерфейс не должен использоваться для принятия медицинских решений.
